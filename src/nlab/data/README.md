# Bundled radionuclide catalogue

`radionuclide_lines.sqlite3` is generated by
`scripts/build_radionuclide_catalog.py` from the official NNDC ENSDF API
snapshot whose `dataGeneratedAt` value is `2026-08-10T15:57:13Z`.

The builder converts ENSDF relative gamma intensity to photons per 100 parent
decays using the normalization-record photon factor and decay branching ratio.
Every displayed row retains the source dataset id, name, evaluation cutoff
date, and API URL. Limit-only and uncertain records are stored but are not
recommended for the default GUI overlay. A single separately attributed
DDEP/IRDFF-II row preserves Na-22's 511 keV annihilation reference.

The generated database is committed so installed applications remain offline
and deterministic. Do not edit it manually; update the pinned source release,
run the builder, review known reference nuclides and row counts, and commit the
new artifact together with its tests and documentation.
